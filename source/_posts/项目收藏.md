{% hideToggle AI 编码代理 %}
这类项目是当前最火的赛道——让 AI 直接在终端里帮你写代码、跑任务。

- [Cherry Studio](https://github.com/CherryHQ/cherry-studio) ⭐ 51.9k — AI 生产力工作室，集成智能对话、自主代理和 300+ 助手，统一接入前沿 LLM。桌面 GUI 应用，适合非终端用户高效使用 AI。亮点是开箱即用的丰富助手生态和跨平台桌面体验。

- [Goose](https://github.com/aaif-goose/goose) ⭐ 54.4k — 开源可扩展 AI 代理。超越简单的代码建议，支持安装、执行、编辑和测试，可搭配任意 LLM 使用。亮点是基于 MCP 开放标准的扩展架构（70+ extensions），面向终端和自动化场景。

- [Warp](https://github.com/warpdotdev/warp) ⭐ 65.1k — 诞生于终端的 agentic 开发环境。内置 Warp Agent，也可接入 Claude Code、Codex、Gemini CLI 等编码代理，把终端变成编排代理的工作台。

- [Toad](https://github.com/batrachianai/toad) ⭐ 3.4k — 终端 AI 统一接口。用一个工具统一管理 Claude、Gemini、Codex 等不同厂商的编码代理，可同时运行多个代理并统一查看状态，解决终端环境下多 AI 后端切换的痛点。

- [CC-Switch](https://github.com/farion1231/cc-switch) ⭐ 133.5k — 跨平台桌面 All-in-One 管理器（Tauri 构建）。统一管理 Claude Code、Claude Desktop、Codex、Gemini CLI、Grok Build、OpenCode、OpenClaw、Hermes Agent、MiniMax Code 共 9 款 AI 编码工具的 API 供应商配置，一键导入、托盘即时切换，并统一管理 MCP 与 Skills。亮点是真正做到了多工具配置的一站式管理。

- [Codex Web](https://github.com/0xcaff/codex-web) ⭐ 301 — Codex Desktop 的浏览器前端。后端留在你控制的机器上（云服务器、家庭实验室、Mac mini），合盖后代理继续运行，可从任意设备的浏览器重连，解决了纯终端交互不够直观的问题。

- [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) ⭐ 228.5k — DeepSeek 官方开源的 agent harness（dsh），"一切皆插件"架构，基于 Cordis 构建。一行 `npx @deepseek-ai/dsh web` 即可启动 Web UI。亮点是官方出品加彻底插件化的架构；注意仍处 developer preview，迭代快、存在破坏性变更。

- [oh-my-pi](https://github.com/can1357/oh-my-pi) ⭐ 31.7k — 把 IDE 接线进来的终端 AI 编码代理（pi-mono 的 fork）。支持 hash-anchored 编辑、14 个 LSP 操作、Python/浏览器/子代理和 60+ 模型提供商，核心约 8 万行 Rust。亮点是把 IDE 的代码智能直接接进终端代理。

- [OpenCodeReview](https://github.com/alibaba/open-code-review) ⭐ 35.7k — 阿里开源的代码评审工具，源自阿里内部官方 AI 评审助手，服务数万开发者后开源。确定性流水线 + LLM Agent 混合架构，行级精确评论，内置 NPE、线程安全、XSS、SQL 注入等多语言规则集。亮点是同模型下 Precision/F1 显著高于通用代理，token 消耗仅约 1/9。

- [Pi](https://github.com/earendil-works/pi) ⭐ 106.8k — AI 代理工具包（单体仓库）：统一多提供商 LLM API、Agent 运行时、TUI 终端 UI 库和可自扩展的编码代理 CLI，Discord/Telegram 聊天自动化在独立仓库 pi-chat。亮点是从底层 LLM 调用到上层编码代理全链路自研，供应链加固严格（依赖锁定、npm-shrinkwrap、定时签名审计）。
{% endhideToggle %}

{% hideToggle AI 代理技能与框架 %}
这类项目关注 AI 代理的能力扩展和编排方式。

- [Superpowers](https://github.com/obra/superpowers) ⭐ 288.3k — 代理技能框架与软件开发方法论。提供一套完整的 agentic skills 框架，让 AI 编码工具遵循结构化的开发流程。亮点是经过实战验证的方法论，而非理论框架。

- [MattPocock Skills](https://github.com/mattpocock/skills) ⭐ 264.8k — 面向"真实工程"的实战代理技能集。来自 Total TypeScript 作者 Matt Pocock 的 skills 集，提供 /grill-me、/grill-with-docs 等需求对齐技能，让代理就你的计划不断追问直到设计收敛，解决代理与用户需求错位的核心痛点。亮点是技能小巧、可组合、易改造，适配任意模型。

- [SkillOpt](https://github.com/microsoft/SkillOpt) ⭐ 17.2k — 微软出品的文本空间技能优化器。通过轨迹驱动编辑和验证门控更新，为冻结的 LLM 代理训练可复用的自然语言技能，输出 best_skill.md 制品。解决手写 agent 技能难以调优、效果不稳定的问题。亮点是学术级方法论与可直接部署的技能制品相结合。

- [Ponytail](https://github.com/DietrichGebert/ponytail) ⭐ 141.6k — 让 AI 代理像"最懒的资深工程师"一样思考的技能。核心理念是"最好的代码是你永远不用写的代码"，引导代理优先复用、删除、减少改动。解决代理过度生成代码、引入不必要复杂度的问题。亮点是反直觉的"少即是多"工程哲学。

- [OpenCLI](https://github.com/jackwener/OpenCLI) ⭐ 29.4k — 将任意网站变成 CLI 工具。借助 AI 代理使用你已登录的浏览器，把 Web 操作转化为命令行交互。亮点是支持已登录状态的浏览器复用，绕过认证难题。

- 🆕 [Open Connector](https://github.com/oomol-lab/open-connector) ⭐ 5.8k — 开源的 AI 代理连接网关（Pipedream/Composio 替代）。一次授权用户的 SaaS 账号，再通过 SDK、CLI、MCP、HTTP 和 OpenAPI 把 1000+ 提供商、10000+ 预置 Action 暴露给代理。亮点是可托管也可自建，OAuth 一次接入到处用。

- [MemPalace](https://github.com/MemPalace/mempalace) ⭐ 59.1k — 开源、本地优先的 AI 记忆系统，完全免费。官方自报 LongMemEval raw R@5 96.6%（数据与逐题结果随仓库提交），明确不做与 Mem0/Zep 等的横向对比。解决 AI 代理缺乏长期记忆的问题。

- [Herdr](https://github.com/herdrdev/herdr) ⭐ 39.3k — 编码代理的常驻运行时（"the runtime your coding agents live on"）。后台服务器架构，终端活在它内部：合盖/断网后进程继续跑；机器重启后恢复布局，且仅对支持 native session restore 的代理真正 resume。可从任意终端或 SSH 重连。代理还能通过 CLI 与 socket API 自主操控它（互相开 pane、发提示）。单一 Rust 二进制，支持 Claude Code、Codex、Cursor、OpenCode 等。

- [Paseo](https://github.com/getpaseo/paseo) ⭐ 17.6k — 从桌面和移动端编排多个编码代理。支持 Claude Code、Codex、Copilot、OpenCode、Pi 等主流代理，提供 iOS/Android 客户端，出门在外也能接管和调度本地跑着的代理任务。

- 🆕 [Munder Difflin](https://github.com/chaitanyagiri/munder-difflin) ⭐ 7.6k — 在本机跑「一整层办公室克隆人」的多代理 harness（Electron 桌面应用）。复用你已有的 Claude Code、Codex、Gemini CLI、OpenCode、Pi、Cursor 等订阅，把终端编码 CLI 变成可互相传话、路由和记忆的工位角色。亮点是不另买席位、可视化办公楼层。

- [Awesome Persona Distill Skills](https://github.com/xixu-me/awesome-persona-distill-skills) ⭐ 4.7k — 以人物关系、纪念场景和方法论视角为主题的代理技能集合。解决的是 AI 在人际交往和情感场景下的表达能力问题。注意：GitHub API 现对原地址返回 404，仓库可能已删除或私有化，本轮未能刷新 star 数。

- [dsh-anchored-standard](https://github.com/xiaobright/dsh-anchored-standard) ⭐ 3.8k — 社区实验性 DeepSeek Harness 预设（非官方）。两阶段锚定：首个请求走 Minimal（2 个工具、无注入上下文），稳定后晋升到 resident catalog（bootstrap 双工具 + discovery），而不是完整 Standard。2026-09-10 起因 V4 Pro 退役处于 frozen。另有 Zero-Anchored、Whoami 两个 0 工具变体。

- [book-to-skill](https://github.com/virgiliojr94/book-to-skill) ⭐ 31.1k — 把任意技术书籍或文档集变成统一的代理技能。支持 PDF/EPUB/DOCX/MD/HTML/RTF/MOBI 等格式，产出符合开放 Agent Skills 标准（SKILL.md），Claude Code、GitHub Copilot CLI、Amp 通用。解决"书读完就忘、知识无法随取随用"的问题。

- [Harness Anything](https://github.com/yb2460/harness-anything) ⭐ 1.9k — AI 代理全栈操控中心（Windows）。47 个 CLI 命令经 COM 自动化操控 WPS/MS Office（Word/Excel/PowerPoint），Zotero 集成 27 个学术 Skill，另有 Photoshop / Illustrator COM 操控。让 AI 代理直接驱动办公和设计软件。

- 🆕 [Pydantic AI](https://github.com/pydantic/pydantic-ai) ⭐ 20.0k — Python 侧的类型化 AI SDK / 代理循环。同一套 agent 可跑在 Web、终端、语音通话、后台队列和 GitHub Actions，模型切换是字符串级，图像生成与 embedding 同箱。亮点是端到端类型约束，Pydantic 生态原生。

- 🆕 [LLM-as-a-Verifier](https://github.com/llm-as-a-verifier/llm-as-a-verifier) ⭐ 3.2k — 通用代理验证框架，给任意代理细粒度反馈而无需额外训练。用评分 token 的 logprob 期望做细粒度打分，可用于测试时扩展、进度跟踪和强化学习。官方称在 Terminal-Bench、SWE-Bench Verified 等代理基准上达到 SOTA（以论文/仓库自报为准）。

{% hideToggle AI 提效与优化 %}
这类项目关注如何让 AI 工具跑得更快、用得更省。

- [RTK](https://github.com/rtk-ai/rtk) ⭐ 80.9k — CLI 代理，在常见开发命令的输出传入 LLM 之前进行过滤和压缩，使命令输出的 token 减少 60-90%（针对代理读取的 bash 输出，不等于账单等比下降）。单个 Rust 二进制文件，零依赖，支持 100+ 命令，开销 <10ms。亮点是极低性能开销和零侵入接入（只需设为代理即可生效）。

- [Headroom](https://github.com/headroomlabs-ai/headroom) ⭐ 72.8k — 在工具输出、日志、文件和 RAG 数据传入 LLM 之前进行内容感知压缩：JSON 数据减少 60-95% 的 token，编码代理场景官方称约减少 20% token，且不影响回答质量。提供库、零改代码代理和 MCP Server 三种接入方式。亮点是显著的 token 成本节省。

- [AirLLM](https://github.com/lyogavin/airllm) ⭐ 34.5k — 大幅降低 LLM 推理显存占用的推理库。70B 模型单张 4GB GPU 即可运行，无需量化、蒸馏或剪枝；405B 约需 8GB，DeepSeek-V3 671B 约 12GB；稀疏 MoE 模型按专家流式加载，甚至能在 4GB 以内跑最大开源模型。让消费级硬件跑超大模型成为可能。

- 🆕 [FreeToken](https://github.com/FlashML-org/FreeToken) ⭐ 13.1k — 面向消费级硬件的边端 MoE 推理引擎。把 GPU/CPU/主机内存当成弹性推理平台，宣称可在游戏 PC 上本地跑 290B+ 级开源 MoE（DeepSeek-V4-Flash、Qwen、GLM 等），提供 Anthropic/OpenAI 兼容 API 对接编码代理。亮点是专家缓存与语义 KV 缓存，针对 agent 场景减少重复预填。

- [Readme AI](https://github.com/eli64s/readme-ai) ⭐ 3.0k — AI 驱动的 README 文件生成器。自动分析项目结构和代码，生成专业规范的 README 文档，省去手动编写的繁琐工作。
{% endhideToggle %}

{% hideToggle 学术科研工具 %}
面向研究人员的效率工具，覆盖论文写作、绘图、灵感获取等环节。

- [Paper2Poster](https://github.com/Paper2Poster/Paper2Poster) ⭐ 3.9k — NeurIPS 2025 Dataset & Benchmark Track 的多代理论文海报生成系统。输入一篇论文 PDF，多代理 PosterAgent 自动输出学术海报（.pptx）。官方基准上优于 GPT-4o / PPTAgent / OWL，并称相对 GPT-4o 方案少用约 87% token。

- [PaperX](https://github.com/yutao1024/PaperX) ⭐ 71 — 多模态学术演示生成框架。从论文 PDF 自动生成 PPT、学术海报和宣传页，统一框架、低成本、设计现代。附 arXiv 论文与 HuggingFace 在线 demo，与 Paper2Poster 同属"论文转演示"赛道但覆盖面更广。

## Token 压缩：RTK vs Headroom

| 维度 | RTK | Headroom |
| --- | --- | --- |
| 实现语言 | Rust（单二进制，零依赖） | Python/TypeScript |
| 压缩方式 | CLI 代理，过滤和压缩命令输出 | 库/代理/MCP Server，内容感知压缩日志和 RAG 数据 |
| 支持范围 | 100+ 常见开发命令（git、ls、cat 等） | 通用文本压缩，不限命令类型 |
| 性能开销 | <10ms | 较低 |
| 接入方式 | 设为系统代理即可生效，零配置 | 需选择库/代理/MCP 其中一种接入 |
| 压缩率 | 命令输出 token 减少 60-90% | JSON 数据 60-95%，编码代理场景约 20% |
| 选择建议 | 追求极致性能和零配置 → **RTK** | 需要灵活接入方式或压缩 RAG 数据 → **Headroom** |
